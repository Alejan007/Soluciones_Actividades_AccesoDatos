# Componentes_04

Cliente Swing que carga las implementaciones de los DAO usando la característica reflexión de JAVA.

### Requisitos

- Proyecto `Ficheros_09` en el classpath


Las claves de rutas y separadores (`continente.ruta.fichero`, `pais.ruta.fichero`, etc.) las usan los DAO de `Ficheros_09`. Deben ser adaptadas a cada equipo.
